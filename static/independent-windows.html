How Overlapping Windows Share Information

The mechanics behind the gold dots, the SE ribbon, and the “Independent only” toggle.

Imagine a 40-year record. You study it by sliding a fixed-length window across the timeline and measuring something in each window. The measurements overlap heavily — each window shares almost all its data with the next. So the apparent count of windows is not the count of independent pieces of evidence.

This page strips away the finance and builds the idea from scratch: first on a plain timeline, then onto the abstract “horizon” x-axis of the Active vs Passive: Delta vs Horizon chart, so that axis stops feeling opaque.

Colour convention (consistent with the main chart): ▬ teal = all overlapping windows  ·  ▬ gold = independent (non-overlapping) windows.

The invariant
An independent selection is a combination of windows that don’t share data. Many such combinations exist — members are your choice. But the count is not your choice: the maximum number of non-overlapping L-year windows that fit in a T-year span is exactly ⌊T ÷ L⌋, for any combination, because each window consumes L years of exclusive length.

This is why the honesty math keys to the count alone. The lone gold window at a 20-year horizon is one arbitrary representative of “≈1 independent window’s worth of information” — the 1 is solid even though the membership is a coin-flip.

4 · Why It Matters

Now put measured values on the timeline. Because this is a synthetic example, we build the data ourselves: 480 months drawn at random from a process whose average is exactly 0. In this toy we therefore know that 0 — call it the generated mean — and can ask how well our windows recover it. Any handful of windows will average to something near 0 but rarely exactly 0; that’s the sample mean, which scatters by luck of the draw. The error bars measure how far the sample is likely to sit from the value we generated from.

The horizon scatter shows the real chart’s behaviour: at long horizons the teal haze converges vertically (long-window means cluster near the generated value) while the gold dots thin — so it looks like ever-more-precise evidence while actually resting on ever-fewer independent windows.

Real markets give no such number. There is no value waiting to be recovered — only the one history that happened and whatever model we lay over it. This widget can label a line “generated mean” precisely because it is a simulation, which is exactly why one history of returns cannot, on its own, tell you there is one.

The honest (gold) bar brackets the true mean far more often than the naive (red) bar; the naive bar is overconfident because it treats ~99%-redundant windows as independent evidence. At long horizons even the honest bar misses frequently — with only one or two independent windows no interval can be reliable, and the honest bar is the one that doesn’t pretend otherwise.

Effective Sample Size

The concept has a name: effective sample size (ESS). When observations overlap or are autocorrelated, the nominal count Nall overstates how much independent information you have. The honest count is ⌊T ÷ L⌋, regardless of which combination you pick — the membership is arbitrary, the count is robust.

This is the mechanic behind three features of the Active vs Passive: Delta vs Horizon chart:

  • ● Gold dots — each is one non-overlapping window at its horizon; the count per column is ⌊T ÷ L⌋.
  • ● Violet SE ribbon — width is keyed to ⌊T ÷ L⌋, not to the nominal Nall; it widens toward long horizons because the independent count collapses, even as the teal haze looks increasingly tight.
  • ● “Independent only” toggle — collapses the dense haze to the handful of truly non-overlapping threads, making the data scarcity visible in one click.
